# Tabungin — Kalkulator & Analisis Kesehatan Keuangan

Aplikasi kalkulator dan analisis kesehatan keuangan interaktif realtime untuk Pribadi dan Perusahaan lengkap dengan proyeksi saldo 12 bulan.

## Menjalankan Secara Lokal

**Prasyarat:** Node.js

1. Instal dependensi:
   `npm install`
2. Jalankan server pengembangan:
   `npm run dev`
3. Build untuk produksi:
   `npm run build`
